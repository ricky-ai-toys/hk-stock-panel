# 专业分析报告写作规范

## 结构要求
1. 摘要/核心结论先行，忙碌的人只看前三行
2. 数据支撑结论，每个判断附数字
3. 风险提示放正文（是结论的一部分）
4. 方法论/口径放附录

## 写作原则
- 正文准入标准：删掉这段后故事线还能否自洽？能→移附录；不能→留正文
- 表格>段落，用数字不用模糊词（不说"市场很大"，说具体数字）
- 至少用两个数据源交叉对比
- 没有数据支撑不猜因果
- 不给出明确买卖建议，保持客观分析立场
- 区分已知事实（带数据来源）vs 推断（标注⚠️）

## 语言风格
- 专业但不晦涩，用短句
- 关键数字用**加粗**标注
- 利空信号用🔴，利好信号用🟢
- 减持/增持说明幅度（多少万股、占比多少）
- 成本/价格用HK$开头
- 避免主观情绪化用词（"暴涨""暴跌""疯狂"），使用客观描述
